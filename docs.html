REFERENCE GUIDE

Build programs for the JPU.

The CPU has 64 8-bit registers, two 256-byte RAM banks, an 8-slot call stack, and a 256-instruction ROM. Use the ROM Editor to configure one instruction at a time, save it, then run it in the Dashboard.

Quick start

  1. Open ROM Editor and choose the instruction fields.
  2. Select SET to place it at the current address, then move with PC+ or PC-.
  3. Select SAVE to keep the ROM in this browser.
  4. Open Dashboard and use STEP or RUN to execute it.

Instructions

Opcode Meaning
NOP Does nothing; moves to the next instruction.
JMP Jumps to the operand address (0–255).
LDI Writes the operand value into the selected write register.
ALU Runs the chosen ALU operation using A and B, then writes the result to the selected register.
STR0 / LOD0 Store to / load from RAM bank 0 at the operand address.
STR1 / LOD1 Store to / load from RAM bank 1 at the operand address.
CAL Pushes the next address onto the end of the stack and jumps to the operand address.
RET Pops the last stack value and jumps to it.
PSHL Pushes the selected B register onto the last (right-hand) end of the stack.
PSHF Pushes the selected B register onto the first (left-hand) end of the stack.
POPL Removes the value at the last (right-hand) end of the stack.
POPF Removes the value at the first (left-hand) end of the stack.
HLT Halts the current execution step.

ROM Editor fields

A Source / B Source
Input registers used by ALU. B can also be the immediate operand.
Write Register
Destination for LDI, LOD, and ALU results. R0 is fixed at zero; ACC is R63.
Operand
An 8-bit immediate value or address (0–255).
Set Flags
For ALU operations, updates condition flags used by conditional instructions.
Invert
For ALU operations, bitwise-inverts the 8-bit result before writing it.
Use Condition
When enabled, executes the instruction only if its selected condition flag is true.

ALU and flags

The ALU supports ADD, SUB, MUL, MUL2, MOD, SHL, SHR, ROR, ROL, AND, NAND, OR, NOR, XOR, MAX, and MIN. Flags include zero/non-zero, most/least-significant-bit, carry/no-carry, comparisons, maximum, and prime/not-prime.

Known limitations

ROM saves are stored only in this browser until you export a .jpur file. The hidden Tests page is a convenience tool, not a secure area. Accounts and cloud saves are planned for a later version.
